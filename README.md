# Machine Learning Classification Dashboard

A Streamlit application that compares multiple machine learning classification models using the Bank Marketing dataset. Users can also upload their own CSV dataset for analysis.

## Features

- Automatic analysis of the Bank Marketing dataset
- Upload your own CSV dataset
- Train multiple classification models
- Compare model performance
- View classification reports
- View confusion matrices
- Download results as CSV

## Technologies Used

- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
- UCI ML Repository (ucimlrepo)

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
